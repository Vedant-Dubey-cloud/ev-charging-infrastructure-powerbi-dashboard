# Data Dictionary

| Column | Description |
|---------|-------------|
| Station Name | Name of the EV charging station |
| Fuel Type Code | Fuel type available (Electric) |
| Street Address | Station address |
| City | City where the station is located |
| State | U.S. state |
| ZIP | ZIP code |
| Status Code | Operational status of the station |
| Access Code | Public or private accessibility |
| EV Network | Charging network provider |
| EV Level2 EVSE Num | Number of Level 2 charging ports |
| EV DC Fast Count | Number of DC Fast Chargers |
| EV Connector Types | Supported connector types |
| Open Date | Date the station became operational |
| Latitude | Geographic latitude |
| Longitude | Geographic longitude |
| Facility Type | Type of facility hosting the station |
| EV Pricing | Charging cost information (if available) |
